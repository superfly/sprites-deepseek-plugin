# Support

## Plugin bugs

Use the repository's [bug report form](https://github.com/superfly/sprites-deepseek-plugin/issues/new?template=bug_report.yml) for reproducible problems with installation, Cordis composition, OAuth, MCP tools, packaged skills, or CI validation.

Include the plugin version, DeepSeek Harness version, Node.js version, operating system, relevant redacted output, and the smallest reproduction. Never include credentials, OAuth cache files, browser cookies, private data, or production logs.

## Product questions

- Sprites usage and MCP behavior: [Sprites documentation](https://docs.sprites.dev/) and the [Fly.io community](https://community.fly.io/).
- DeepSeek Harness plugin behavior: [DeepSeek Harness plugin documentation](https://deepseek-harness.github.io/deepseek-harness/en/develop/basic/).
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), not the public issue tracker.

This repository's issue tracker is not a channel for account, billing, or production-incident support. See [Fly.io support options](https://fly.io/docs/about/support/) for those requests.
